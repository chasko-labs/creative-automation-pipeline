# comfyui workflows — reproducible campaign graphs

Two frozen API graphs. placeholders get filled by drivers, never hand-edited.

- `kodiak-blog-scene-turbo.json` — photographic blog scene. DreamShaperXL Turbo, euler 8 steps cfg 2.0, 1344x768. driver: `scripts/comfy_blog_scene.py <seed> <pos_file> <neg_file> [prefix]`. fills node 2 positive, node 3 negative, node 5 seed, node 7 prefix. output lands in `input_assets/blog/`.
- `kodiak-ink-ingredient-base.json` — ink ingredient study. SDXL base 1.0, euler 25 steps cfg 7.0. node 2 takes full subject + geometry positive, node 3 is the locked negative. same seed/prefix substitution.

To try in the browser UI: open the box at `:8188`, drag one of the `-ui.json` files onto the canvas (or Workflows sidebar → Import). Replace the node-2 text, set seed, Queue. The plain `.json` files are API format for headless runs — POST them to `:8188/prompt` after substitution, which is what `scripts/comfy_blog_scene.py` does.

Committed renders stay in `input_assets/blog/` and `input_assets/sprint2-ingredients/` with seeds in manifests. no `/tmp` renders count as assets.
- `kodiak-ristra-controlnet.json` — **ristra ControlNet/IP-Adapter path (30-sec)**. SDXL base 1.0 + ControlNet lineart/depth for ristra geometry (Capsicum annuum var. annuum). Pillow-generated silhouette `red-chile-controlnet-lineart.png` (and depth alt) encodes the *real* ristra: 6 tapered pods, single string, top knot, star calyx, leather micro-wrinkles. ControlNet locks geometry; text prompt only styles. API graph has 10 nodes: 1 checkpoint, 2 positive, 3 negative (now bans red/burgundy/color wash + leaves/branches/foliage + ribbed/warty/dotted), 4 LoadImage (control map), 5 ControlNetLoader, 6 ControlNetApplyAdvanced (strength 0.85), 7 latent, 8 KSampler (seed 711020, cfg 5.5), 9 VAEDecode, 10 SaveImage. Driver: `python scripts/generate_ristra_controlnet.py` (0.1s, Pillow-only) re-creates the control maps; drop the PNG into ComfyUI `input/` and Queue. Depth variant: swap node 4 image to `red-chile-controlnet-depth.png` and node 5 to `control_v11f1p_sd15_depth.pth`. IP-Adapter alt: replace nodes 4-6 with IPAdapterLoader + IPAdapterApply fed by `red-chile.png` 710405 (the only txt2img ristra geometry that ever rendered).
