## Key Decisions
- **Data-model repair, not code branch**: ATL March fix is a data patch (`seasonal_moments` addition), not a `if (market===ATL) months.push(3)` hack. Keeps `find(p.market===selected)` invariant; every other market keeps its model as source. Rejected: hardwired fallback in `data-core.js` — violates data-model contract.
- **Supplement, not override**: `frontierSeasonLine` keeps `monthly_ingredients["2026-03"]` as source (`strawberries`) and appends `favorite_flavors`/`cue`; prevents March→`pumpkin spice` regression. Rejected: moment `available_ingredients` overriding monthly grid.
- **Adversarials after DoD grounding**: review `coverage-matrix.md` + `campaign-pipeline-data-model.md` + `ci-local-gate.md` + `how-we-launch-in-every-town.md` + target tests to anchor DoD, then dispatch 3 isolated adversarials. Rejected: dispatching blind adversarials before ATL patch — would re-find known hole and waste tokens.
- **Isolated worktrees for doc/adversarial notes, not for data fix**: data patch is atomic on main worktree; adversarial findings land in isolated worktrees or `.agents/plans` notes to avoid collateral edits (`git status` clean). Rejected: doing adversarial analysis in-place without isolation.
- **Live Bedrock, not local**: all `/generate` probes use Bedrock (nova-pro) per speed directive; local mock only for unit fixtures. Rejected: local model for verification — mismatches prod.

## Recommended Approach
1. Re-ground DoD/targets from repo files and tests (no guesswork).
2. Rebuild artifacts deterministically from patched `retailer-frontier-pairs.json` (bake `recipe-cards-data.js` + `recipe-i18n-data.js` + `data-core.js` cues) so any hidden divergence fails locally.

4. Triage adversarial findings against DoD; fix data/model gaps (never code hardwires), add durable tests where coverage was missing.
5. Re-run full gate (`pytest -q`, `pre-push` ruff, build-regional-scoreboard parity) and live smoke (`/generate` distinct `s3_uri` for spread markets/seasons), then bump version and deploy to both hosts.
