# Briefs — Kodiak is primary, generic example is archive

Kodiak custom campaigns live here first — every file that starts with `kodiak-` is the real brand, real palette #3B2316/#E8530E, real voice "real food for real adventures," and real local targets like Las Cruces green chile.

Start with these:

- `kodiak.yaml` — Park City Wasatch, Keep It Wild, 14 grams protein, Power Cakes + Bear Bites + Oatmeal Cup
- `kodiak-publix.yaml` / `kodiak-target.yaml` / `kodiak-costco.yaml` — same products, tuned per retailer (Publix family's frontier, Target fuel your frontier, Costco stock the frontier)
- `kodiak-on-the-go.yaml` — busy students, 5 grams for busy mornings (replaces old back-to-school, always useful)
- `kodiak-diner.yaml` — local diners that flip cakes
- `kodiak-subscription.yaml` — home delivery, 15 percent off plus free shipping over 45

`example.yaml` and `example.json` are kept only as a tiny generic smoke test for the pipeline shape — they use a made-up brand to prove the pipeline works without any Kodiak assets. New work should copy a `kodiak-` brief, not the generic one.
