Procedural check — international write date, versioning

Every file the pipeline writes is KODIAK-CAKES-{PRODUCT}-{REGION}-{LOCALITY}-{CHANNEL}-{RATIO}-{YYYYMMDD}-v01.png — year first per ISO 8601, lower case product, hyphens, version zero-padded. Headers carry YYYY-MM-DD and BCP 47 language tags like en-US. Details at docs/iso-naming-conventions.md.
