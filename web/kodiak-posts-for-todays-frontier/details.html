9 · Axis A — four-view responsive dimension S11

Grades each element's form + function across mobile 375 / tablet 768 / desktop 1440 / ultrawide 2560.

Live CSS reality: TWO layout breakpoints (860 for the main grid + prompt row, 640 for the control row) and NO breakpoint above 860px. Desktop 1440 and ultrawide 2560 render byte-identical CSS; mobile 375 and tablet 768 are also undifferentiated. Effectively two states — narrow (≤640) and wide (>860) — with a thin 641-860 band. 10 · Axis B — translation as a first-class element S12 · highest-value gap

The site advertises localization on every surface but renders ZERO per-market translated copy. The data exists and is rich; the render path is a deliberate no-op.

Core finding: renderLangChips() (index.html L748) is a hard no-op that DELETES its own target from the DOM. The data is abundant — market-languages.json carries 73 markets, top-2 non-English language each with real ACS S1601 percentages, 219 total localized variants (auto_produce:true, nova_proven:true). The gap is purely render.

S12 — translation is a first-class rendered element, not a badge. Any surface that claims localization must render actual localized copy for the selected market, sourced from market-languages.json (or the live localize tool), driven by the selected market's top_languages[]. A hardcoded language list that never changes with market selection is a violation. Wave 2/3 deliverable: wire selected market → top_languages[] → localized caption previews + update #marketLangLine + #featuredFrontier; replace renderLangChips from delete-stub to real renderer.

A migrated control keeps the kodiak look by mapping kodiak tokens onto the sp-* component's theming custom properties (feed --colors-* / --radii-* / --shadows-*). Any spectrum migration touching focus styling must resolve to the signalRed TOKEN, not the raw --red var.

8 · Open standards decisions D1–D3

Flag, do not silently fix — these are design-system governance calls owned by the product owner.

D1 — the signal red B51E14. Used for links, .btn.orange, header title block. Not originally a brand token and it competed with blazeOrange as "the accent." Resolved: adopted as color.brand.signalRed token; the :root alias --red now routes through it. Blocks S1 closure until deploy confirms. D2 — inline palette duplication. The :root{} block was copied into both HTML files. Resolved: reduced to token aliases only (single-sourced through styles.css); the --adobe svg literal stays as a documented exception. D3 — chocolate 382316 vs bearBrown 3B2316. 3-hex drift, visually identical. Resolved: normalized to the token everywhere; --chocolate/--brown now alias bearBrown.
