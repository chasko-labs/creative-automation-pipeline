CDK stacks live

Single canonical app, adopted in place (#122). Five stacks.

  • generate-stack — GenerateLambda (brief-to-hero handler) behind a public dev-open Function URL the site calls directly; Bedrock grants for Nova Pro, Stability control-structure + outpaint, Nova embed + Titan fallback.
  • data-stack — DynamoDB localization-memory + retail-network (pay-per-request); S3 pipeline-log + style-library buckets (TLS-only policy).
  • bedrock-logging-stack — cross-region Bedrock invocation logging + X-Ray tracing (#122).
  • observability-stack — pipeline observer spans, scorecard + compliance gates (#42).
  • browser-observability-stack — RUM + CloudFront log bucket for the live frontend.
  • Example — generate-stack Lambda — GenerateLambda, container image, memorySize 3008, timeout 300, public Function URL (AuthType NONE) the site POSTs /generate to; Bedrock grants cover Nova Pro, Stability control-structure + outpaint, and Nova multimodal embeddings with Titan fallback (amazon.nova-2-multimodal-embeddings-v1:0).

Database schemas live

Every store the pipeline reads or writes, with key layout and a real row.

  • DynamoDB kodiak-creatives-localization-memory — pay-per-request, PITR on, RETAIN on delete. Single-table keys: pk = MARKET#<market> (HASH), sk = LANG#<lang>#MSG#<sha1-16> (RANGE) — built by localize_memory.build_key. The /localize path checks it before calling Translate, so repeat captions cost a read, not a translation.
  • Example row — pk MARKET#US-W-SPOKANE / sk LANG#en#MSG#782a7f241acbbb92 → text "Spokane Falls to the ponderosa pines — protein-packed whole grains for your Spokane frontier", provider precomputed, source dynamodb (live scan 2026-09-08).
  • DynamoDB kodiak-creatives-retail-network — pay-per-request, RETAIN. Key: store_id (HASH) + GSI byMarket on market (projection ALL) for market→stores lookup. Example: 0 items as of 2026-09-08 — store discovery not yet ingested, so the API falls back to the curated JSONL.
  • S3 Vectors kodiak-vectors / index kodiak-assets — multimodal embeddings, 1024 dims, cosine distance, float32 (Nova multimodal default; Titan embed fallback). Powers "riff on past content" similarity over past DAM renders. RETAIN on delete.
  • S3 DAM chasko-creative-dam-946179428633-us-east-1 — versioned, KMS SSE + bucket-key, full public-access block, TLS-only policy, RETAIN. Layout under brands/kodiak/: renders/ (per-campaign packs, e.g. renders/output_kodiak-costco/), renders/restyle-cache/ (content-addressed restyled seeds — under renders/ because the Lambda role grants Put/Get only on renders/* and library/*), raw-ingest/ (source photos, e.g. raw-ingest/kodiakcakes/images/705599011627_FlapjackMix_Buttermilk_Front_1.png), plus heroes/ logos/ recipes/ references/ tokens/ vectors/.
  • S3 pipeline-log + style-library buckets — kodiak-creatives-logs-946179428633-us-east-1 (pipeline observer spans) and the DAM style-library bucket (TLS-only, RETAIN, MPU-abort 7d + renders tiering lifecycle).

Market + localization data live

Where "in season here" and translated copy actually come from — files, schemas, and seams.

  • places[] inline table live — js/data-core.js, 73 markets, one object per line: {market, place, retailer, zip, audience, message, peppers, cheeses, cue}. No endpoint — ships inside the JS bundle. Feeds the headline default, brief YAML, chooser hints, and the in-season fallback chain: artisanal copy → places message/cue → generic-only-if-unknown.
  • Example — US-MW-PARKCITY-84098 → "Park City, Utah 84098", message "Keep It Wild — protein-packed whole grains for your Wasatch frontier. Nourishment for Today's Frontier", cue "Farmers Market at Park City Mountain Resort Wed 11–5 — Jensen Farms peaches, Copper Moose rhubarb, Tagges preserves…".
  • market-languages.json live — data/localization/market-languages.json, 74 markets built from store-finder-markets.json + US Census ACS 5yr Table S1601. Entry: {market, place, zip, top_languages: [{lang_code, lang_name, pct, reason, translate_code, pct_home}]} — the machine_translate flag the frontend checks today lives in the JS inline fallback, not in this file. Delivery is two-tier: inline fallback object in data-core.js (works file:// offline), upgraded at runtime by fetching data/localization/market-languages.json from the site bucket. Consumers: marketLangsFor(), lang chips, tile captions.
  • Example — Park City top_languages[0]: es / Spanish / 5.8% ("ACS 2023 5yr Summit County…"), translate_code es.
  • local-flavor.json (month-aware produce) staged — data/localization/local-flavor.json, schema local-flavor-v1: 6 markets + _default, each {place, source, produce: [{name, months[1-12], peak}]}, reader src/creative_automation/local_flavor.py (local_flavor_for(market, month), tested). Honest status: UNWIRED on both sides — no JS reads it, no Python caller imports it. The UI still uses the 5-entry JS flavorMap plus the places fallback. Wire it before quoting it.
  • Example — Pescadero: Castroville artichokes months [3,4,5,6] peak 4; Marin goat cheese [2,3,4,5,6]. Default row covers all 12 months with "seasonal frontier flavor".
  • POST /localize live — generate_lambda._handle_localize → localize_service.localize(text, market, target_lang) returns {text, source, provider, lang}. Order: English passthrough → precomputed/DynamoDB memory hit → ethics guard (Navajo nv + Zapotec zip return unchanged, never machine-translated) → Translate. Frontend localizeText() posts {text, market, target_lang} to window.KODIAK_LOCALIZE_ENDPOINT ('/localize' on hosted, null offline). Full-mode server-side localization is emptied — frontend owns copy.

Edge + ship path live

How pixels reach the browser and how code reaches the pixels.

  • Static edge — S3 frontier-bryanchasko-com + CloudFront, live at kodiak.bryanchasko.com. scripts/deploy-frontier.sh syncs the 8 top-level files + asset dirs and invalidates; it refuses on version drift.
  • Version stamp — scripts/bump-version.sh sweeps every version-shaped sink mechanically (meta, title, manifest, stamps).
  • CI — CodeBuild everywhere (no GitHub Actions); local pre-push gate replaces the trigger (#129).
  • DAM origin — S3 chasko-creative-dam-946179428633-us-east-1, renders under brands/kodiak/renders/, served presigned.
  • Example — ship + verify — ./scripts/bump-version.sh 0.1.035 && ./scripts/deploy-frontier.sh then read back: curl -s https://kodiak.bryanchasko.com/index.html | grep -o "build 0.1.035-[0-9a-f]*-[0-9]*" must print the stamp whose SHA is the merged HEAD — the deploy is not done until the read-back matches.
