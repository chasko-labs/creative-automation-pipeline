Infrastructure as Code

One canonical CDK app owns the cloud; two shell scripts own the edge. Everything below is read straight from infra-cdk/lib/ — no aspirational boxes.

Design System Inventory Asset Pipeline, Localization & AI Usage Infrastructure as Code

CDK stacks live

Single canonical app, adopted in place (#122). Five stacks.

  • generate-stack — GenerateLambda (brief-to-hero handler) behind a public dev-open Function URL the site calls directly; Bedrock grants for Nova Pro, Stability control-structure + outpaint, Nova embed + Titan fallback.
  • data-stack — DynamoDB localization-memory + retail-network (pay-per-request); S3 pipeline-log + style-library buckets (TLS-only policy).
  • bedrock-logging-stack — cross-region Bedrock invocation logging + X-Ray tracing (#122).
  • observability-stack — pipeline observer spans, scorecard + compliance gates (#42).
  • browser-observability-stack — RUM + CloudFront log bucket for the live frontend.

Edge + ship path live

How pixels reach the browser and how code reaches the pixels.

  • Static edge — S3 frontier-bryanchasko-com + CloudFront, live at kodiak.bryanchasko.com. scripts/deploy-frontier.sh syncs the 8 top-level files + asset dirs and invalidates; it refuses on version drift.
  • Version stamp — scripts/bump-version.sh sweeps every version-shaped sink mechanically (meta, title, manifest, stamps).
  • CI — CodeBuild everywhere (no GitHub Actions); local pre-push gate replaces the trigger (#129).
  • DAM origin — S3 chasko-creative-dam-946179428633-us-east-1, renders under brands/kodiak/renders/, served presigned.
