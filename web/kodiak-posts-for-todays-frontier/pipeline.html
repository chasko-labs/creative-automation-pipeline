Design System Inventory Asset Pipeline, Localization & AI Usage Infrastructure as Code

Generation ladder live

POST /generate runs rungs top-down inside a 24s budget wall and returns real pixels — never a 503. The source label on every response names the rung that produced it.

  • Rung A · packshot live — fastest path: SKU slug maps straight to a DAM packshot, composited with headline + tokens.
  • Rung B · stability restyle live — Nova Pro art-directs (headline + control-structure prompt), Stable Diffusion restyles the composition. 12s cap, fail-fast.
    • Proved #114 (ladder), hardened #117 (fail-fast rung-B calls closed the 33s silent-gap 503).
  • Rung C · pillow composite live — Pillow composes real brand assets under the same Nova Pro art-direction when the image model is slow.
  • Rung D · brand-floor live — deterministic on-brand fallback labelled brand-floor:wall-timeout. Looks flat next to A/B — that label is the honest signal, surfaced per #173.

Nova Canvas is retired by design and is not a path — "Nova magic" means Nova Pro art-direction landing in rungs A–C. Localhost and file:// skip the ladder and render the offline canvas stand-in directly.

Models at work live

Bedrock model IDs, as granted in infra-cdk/lib/generate-stack.ts.

  • Grounded art-director live — the trained voice model cx15b77k5nge (us-west-2, Strands) writes the headline grounded in top-3 retrieved corpus captions (data/vectors/kodiak-embeddings.jsonl, 1024-dim cosine); mock transports are refused, every failure falls back to stock Nova Pro, kill-switch KODIAK_DIRECTOR_GROUNDED.
  • Nova Pro art-director live — amazon.nova-pro-v1:0 (Converse) writes the control prompt + fallback headline (#121).
  • Stable Diffusion family live — stability.stable-image-control-structure-v1:0 (restyle) + stability.stable-outpaint-v1:0, invoked via inference profiles across us-east-1, us-east-2, us-west-2. This is the only photographic rung.
    • Brand look is steered by a color-grade prompt, never hex and never the brand name — diffusion reads color words, not #3B2316, and any brand token renders as garbled pack copy. The frozen style sandwich grades every restyle warm earthy (bear-brown + parchment dominant, muted sage/olive undertone, a single small blaze-orange accent) and appends a text-suppression clause; brand identity is composited in Pillow, never generated pixels. Palette source: design/tokens/kodiak.json as color language in generate.py::KODIAK_PALETTE.
    • Known gap open — the text-suppression clause does not fully hold: at control_strength 0.7 the restyle still occasionally invents a sign or label with garbled lettering, and weakly honors the "no orange sunset sky" negation on landscape scenes. This is a seed / control-strength lever, not a prompt-word fix.
  • Nova Canvas dead — Amazon retired it provider-side (verified denied, account-wide). Proved once end-to-end long ago; there is no console switch to bring it back. Do not confuse with Nova Pro (text art-director, alive) or Nova Act (browser automation, a separate thing entirely).
  • Nova Micro translate live — market copy localization; data-driven machine-translate gate with community-review first-class Navajo.
  • Nova multimodal embed + Titan fallback live — one embed invoke per new DAM asset; dedup by asset_id so re-renders cost zero invokes.

Contribute runbook

How to change what the ladder reads — and how staged work gets into the click path (#179). Conventions live in the linked docs; this card is the index, not a copy.

  • Add a SKU / recipe / hero asset — catalog source is data/products/kodiak-full-catalog.json (88 SKUs). Drop the photo in input_assets/ (heroes) or references/, then rebuild the maps: uv run python scripts/build-sku-photo-map.py --no-verify → data/products/sku-photo-map.json, uv run python scripts/build-theme-asset-map.py --no-verify → data/products/theme-asset-map.json. Both are deterministic (same inputs → byte-identical output), so an empty diff after rebuild means the asset did not match — check the keyword scorer, not the script. Ship to the DAM with DAM_S3_BUCKET=chasko-creative-dam-946179428633-us-east-1 scripts/sync-dam.sh push (tokens → tokens/, input_assets/ → heroes/). First-time seed of tokens + references: scripts/seed-kodiak-s3.sh.
  • Validation + re-render check — rebuild both maps with --no-verify and confirm the new asset appears under its SKU/theme key; then run one preview POST /generate (see Run it) with that SKU and confirm provenance.seed_source names the new asset. Zero-diff rebuild + named seed = done.
  • File a per-market correction — write path is the DynamoDB table kodiak-creatives-localization-memory (us-east-1). Keys: pk = MARKET#<market>, sk = LANG#<lang>#MSG#<sha1-16 of source text> (built by localize_memory.build_key); item carries text + provider + source = dynamodb. CLI example: aws dynamodb put-item --table-name kodiak-creatives-localization-memory --item '{"pk":{"S":"MARKET#US-W-SPOKANE"},"sk":{"S":"LANG#es#MSG#782a7f241acbbb92"},"text":{"S":"…"},"provider":{"S":"human-review"},"source":{"S":"dynamodb"}}' --profile bryanchasko-kiro --region us-east-1. Bulk path: uv run python scripts/precompute-localization.py --dry-run first, then --only-missing to write. Navajo (nv) + Zapotec (zip) are never machine-translated — corrections there go through community review and land with provider = human-review; the ethics guard returns them unchanged until then.
  • Embed / dedup convention — one embed invoke per new DAM asset (Nova multimodal, Titan fallback); dedup by asset_id so re-renders cost zero invokes. Confirm: re-render the same asset and check the Bedrock invocation log group shows no new embedding call for that asset_id.
  • Ready-to-live promotion — per item exit criteria + wiring step: #49 AgentCore runtime — exit: orchestrator deploys beside the Lambda (C1 runtime); wiring: registry tracking moves it into the click path. #50/#43 invocation logging — exit: Bedrock logging stack live in us-east-1 + us-west-2; wiring: every Nova/Stability call watchable, linked from the Run-it incident rows. #39 photo-to-campaign — live: POST /campaigns/from-photo core loop proved end to end (7 route tests green) and the From-a-Photo-or-Prompt entry point now mounts on the campaign page. Judgment calls go to the repo owner before wiring.
  • Read before restating — docs/dam-runbook.md (DAM layout + sync), docs/how-we-launch-in-every-town.md (market rollout), docs/kodiak-image-standards.md (what counts as shippable pixels).

Run it runbook

Operate POST /generate end to end: request shape, source labels, rung forcing, incident signals (#178). Verified against src/creative_automation/generate_lambda.py + generate.py.

  • curl — Function URL is the FunctionUrl output of npx cdk deploy kodiak-creatives-generate (AuthType NONE). Body: prompt required; market, product (default power-cakes), theme, mode (preview default, one 1x1 — full adds the ratio set), seed_key, layers, platforms optional. curl -s -X POST "$FUNCTION_URL" -H 'Content-Type: application/json' -d '{"prompt":"Wasatch dawn flannel family flapjack stack","market":"US-W-SPOKANE","product":"power-cakes"}'. Healthy: {"ok":true,"image_url":"<presigned>","s3_uri":"…","source":"dam:packshot-composite","mode":"preview","renders":[…],"provenance":{…}} — HTTP 200 with real pixels, never a 503.
  • Source labels — dam:packshot-composite = rung A (real box pasted verbatim); bedrock:stability-control-structure = rung B (only photographic rung); bedrock:nova-pro = rung C (Pillow compose, guaranteed-real workhorse); brand-floor = rung D in-ladder floor; brand-floor:wall-timeout = rung D built post-wall in the handler thread; bedrock:nova-pro-fallback = deterministic placeholder hero. provenance.fallthrough_reason explains the drop: null (no fall) / budget-exhausted / bedrock-timeout / model-error / throttle / wall-timeout. A D label is the honest signal, not an error — surfaced per #173.
  • Force each rung (dev only, restore env after) — no dedicated force flag; steer via budget env on the dev Lambda (aws lambda update-function-configuration, which replaces the whole env block — re-send existing vars). Budgets: wall GENERATE_WALL_TIMEOUT_S=22, soft GENERATE_SOFT_BUDGET_MS=24000, rung-B worst-case GENERATE_B_BUDGET_MS=16000 (12s Bedrock read timeout inside), rung-C reservation GENERATE_C_RESERVATION_MS=3000, probe GENERATE_PROBE_BUDGET_MS=5000. A: mapped SKU + product_image layer, full budgets (packshot-first). B: no-packshot product, full budgets, seed resolves. C: GENERATE_B_BUDGET_MS=0 (B skipped → C). D: GENERATE_SOFT_BUDGET_MS=1 (everything skipped → floor).
  • Incident signals — brand-floor spike: check Nova Pro latency first (us-east-1 invocation log group), then Stability denials (fallthrough_reason model-error/throttle = grant or quota, not code). Rung B fails fast per #117 (12s then fall to C) — a slow B is a C with real pixels, not an outage. Confirm in the infrastructure Operate runbook (logs, drift, denials).
  • Offline — localhost / file:// has no /generate and renders the offline canvas stand-in directly.
