# textless pilot seeds (Branch B, Unit 5)

Rung B restyles whatever seed it gets. Every current seed is box art, so every
restyle carries a sign the model mangles into gibberish. These slots hold
TEXTLESS lifestyle photography: no words, letters, logos, labels, or watermarks
anywhere in frame — blank surfaces only. The verbatim box + Pillow overlays stay
the brand carriers; scenes are backdrops.

## Spec per file

- ≥1080px on the short side, landscape or square, JPEG.
- Frontier breakfast theme: cabin table, campfire morning, market stand.
- No text of any kind (this is the whole point — control-structure preserves
  shapes, so a sign in means gibberish out).
- Licensed for commercial use (stock pilot: reversible, fast).

## Wanted (3 pilots)

2. `campfire-morning.jpg` — outdoor morning, cookware, no signage.
3. `market-stand.jpg` — produce/stand texture, no readable labels.
