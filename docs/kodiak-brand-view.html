03 — Campaigns we plan to run — why each is local

Same three products, different retail corridors. That's the hundreds-per-month engine.

  • Keep It Wild (always-on brand) — Power Cakes hero (real asset photo), Wasatch + grizzly-safe, Vital Ground co-badge. Wild in winter ski towns vs porch in southeast — same system, different sky. Prompt kodiak-01 / 06.
  • Frontier Breakfast (retail velocity) — Power Cakes + Bear Bites + Oatmeal Cup × 3 ratios × 3 retailers (Publix southeast family, Target Midwest Gen Z, Costco bulk) = 27 variants. Briefs: kodiak.yaml US-MW vs kodiak-se.yaml US-SE → 9+9 creatives, region-tagged in report.jsonl.
  • Seasonal sprints — Back-to-school Bear Bites lunchbox 9:16, trail oatmeal 16:9, holiday cast-iron stack 1:1. Swap hero prompt kodiak-04 / 05 / 07, keep 6-piece template.

Every creative still runs the brand + legal check: logo present, palette #3B2316/#E8530E/#1A3C34, no guaranteed/miracle/FDA claims. That's the interim style guide until Kodiak publishes one per retailer.

04 — How we produce the assets — watchable loop

S3-backed tokens, local fallback. No creds needed to see it work.

  1. Brief in. YAML names campaign, 3 products, market (US-MW vs US-SE), audience, one headline. Edit briefs/kodiak.yaml.
  2. Dam first. input_assets/power-cakes/hero.png reused → S3 s3://.../power-cakes/hero.png if DAM_S3_BUCKET set → Nova Canvas amazon.nova-canvas-v1:0 1024×1024 cfg 7.5 or mock frontier palette if offline.
  3. Compose to 3 ratios. Pillow: cover fit + 0.18 scrim #1A1110CC, contain hero, message bar 32%@68%, slab headline 56/64/72, caption 22/24, logo 140@24,24, orange 8px bar — all from design/tokens/kodiak.json via token_loader.py.
  4. Check. Logo, palette, prohibited words. Fail still renders but marked fail in report — prevents the 17% class action repeat.
  5. Save + learn. output_kodiak/{product}/{1x1,9x16,16x9}/ + report.jsonl (dma/retailer lift) + preview.html. Sync to S3 brands/kodiak/renders/ with ./scripts/sync-dam.sh push-renders.
